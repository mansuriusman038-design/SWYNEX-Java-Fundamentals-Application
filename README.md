# Student Management App

## Java Fundamentals Internship Task

A simple Student Management Application developed using Java.

### Features
- Add student name and marks
- View all student records
- Automatically calculate Pass or Fail
- Validate student marks (0-100)
- Handle invalid input

### Technologies Used
- Java
- ArrayList
- Scanner
- Object-Oriented Programming

### How to Run
1. Compile: javac Main.java
2. Run: java Main
